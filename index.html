Mosquito seasonality

Rose diagrams of monthly mosquito abundance, built from VecDyn datasets. One rose per county per data provider. Values are mean individuals per trap per day, averaged over the days actually sampled.

Each map lets you switch between all mosquitoes, a single species, sex or trap method, and between a shared scale and a per-site scale. Hover a petal for that month's value and the number of days sampled.

Reading a rose

  • January is at the top, running clockwise, so June and July fall at the bottom.
  • Petal length is the mean number of individuals per trap per day for that month.
  • Each rose is scaled to its own peak, printed above it in the figures. A shared scale flattens the low-abundance species to nothing; the printed peak keeps magnitudes comparable.
  • The number under each month is how many days the site was sampled. A month that was never sampled is drawn differently from one that was sampled with nothing caught, so a gap in effort is never read as a seasonal crash.
  • Species, sex and trap method are never aggregated together.
